CHEFNEARBY MVP

Brand: ChefNearby
Target domain: https://chefnearby.in

This is a production-style static MVP. It can be hosted for free on GitHub Pages, Cloudflare Pages, Netlify or Vercel.

Before going live:
1. Buy/confirm the domain with a registrar.
2. Edit config.js and set your WhatsApp number in international format without + or spaces, e.g. 9198XXXXXXXX.
3. Add your real GA4 Measurement ID, Meta Pixel ID and Google Ads ID when accounts are created.
4. Replace any sample partner/chef content with real verified profiles.
5. Add real cancellation/refund/privacy terms appropriate to the business.

IMPORTANT: This static MVP does not include a secure server/database/payment gateway. For real marketplace bookings we will add a backend (e.g. Supabase/Firebase), admin dashboard, chef onboarding, booking records, availability, Razorpay and notifications.
